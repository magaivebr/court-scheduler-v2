# Signing in

Sign in to your private Court Scheduler account first. Then choose **Connect booking account**, enter the email and password you normally use on KU Leuven Sport, and select **Connect account**. The connection is saved automatically after the official account identity is checked. You do not need to send each field separately or press a separate save button.

If your university account uses SSO, choose **Use official sign-in**. Complete any additional verification on the official screen. The application detects the signed-in booking page and verifies/saves the connection automatically; **Save connection** remains available if an automatic check needs to be retried.

Court Scheduler and KU Leuven Sport are separate accounts. The booking password passes through the host PC to the official login form and is not saved by Court Scheduler. The encrypted reusable session is stored on the host and belongs only to the signed-in scheduler account. The host operator can access that session. Reconnect when it expires.

Closing a connection window cancels that login attempt. Failed sign-in does not overwrite an existing saved connection. A failed or uncertain connection does not authorize a booking. Every actual schedule still requires a successful test and explicit authorization, and the host's live booking switch must be enabled separately.
